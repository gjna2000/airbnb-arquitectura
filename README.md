## Descripción

Este repositorio contiene el levantamiento y la documentación de la arquitectura
de software de **Airbnb**, una plataforma digital de gestión de alojamientos que
conecta anfitriones con huéspedes. Se consideran requerimientos funcionales y no
funcionales, y se justifican las decisiones de diseño tecnológico y estructural.
